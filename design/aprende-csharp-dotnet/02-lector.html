Abrir y cerrar
con using

Aprende a liberar recursos al terminar de leer un archivo, incluso cuando se produce una excepción.

1. Comprende el recurso

Un StreamReader mantiene abierto el archivo hasta que se libera. Un bloque using delimita ese tiempo.

// Ejemplo comentado para estudiar.
// using (StreamReader reader = new("notes.txt"))
// {
//     Console.WriteLine(reader.ReadToEnd());
// }

2. Practica en tu proyecto

Lee el ejemplo, predice el resultado y activa un solo bloque de código en la unidad.
